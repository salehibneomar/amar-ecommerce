# Docs

Reference guides for AmarEcommerce Lite. This folder is optional: nothing in the app, tests, build or agent rules reads it, so it can be deleted or left out of a client project. Start with [README.md](../README.md) and [SETUP.md](../SETUP.md) in the project root.

| File | What is inside |
|---|---|
| [USER_MANUAL.docx](USER_MANUAL.docx) | Word manual for everyone: install on Windows, macOS or Linux, run the shop, find your way around the project and add features with an AI agent |
| [SETUP_ADVANCED.md](SETUP_ADVANCED.md) | Every `.env` setting, Nginx, PHP limits, queue worker, free hosting and updating a live site |
| [SETUP_COMMANDS.md](SETUP_COMMANDS.md) | Every command in one place, including the safe test command |
| [TECHNICAL.md](TECHNICAL.md) | Architecture, folders, database, flows, caching and conventions |
| [DIAGRAM.md](DIAGRAM.md) | ERD, class and sequence diagrams for TECHNICAL.md |
| [HOW_TO.md](HOW_TO.md) | Recipes for everyday changes: titles, links, colors, limits, `.env` |
| [INCOMPLETE.md](INCOMPLETE.md) | Known gaps and ideas for later |
| [OUR_RAG.md](OUR_RAG.md) | How the AI shopping assistant (RAG) works and how to extend it |
