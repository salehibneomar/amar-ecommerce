30 Second Pitch

Say this first.

I built a reusable ecommerce boilerplate in Laravel 13. Every new client shop starts from it, so the shop, checkout, payments, staff panel, reports and an AI shopping assistant are ready on day one. I kept all business logic in services, made every setting configurable, and covered it with over 360 automated tests. It runs on cheap shared hosting and can grow to a VPS without code changes.

Why It Is Unique

The points that set it apart.

A Boilerplate, Not One Shop

The code stays generic. A new client changes config, brand colors and texts, not the core code.

AI Assistant Built From Scratch

A RAG assistant with no AI package. It only suggests real products and falls back to keyword search if the AI is down.

Local and Global Payments

Cash on delivery, bKash or Nagad verified by staff, and Stripe cards. A new gateway is one class.

Runs Anywhere

No queue worker or cron is required, so it works on cPanel. Queues and Redis can be turned on later.

Fine Grained Access

Roles plus per person permissions. Code checks permissions, never role names.

AI Ready Codebase

Clear rules for AI coding agents (AGENTS.md and rule files) keep generated code consistent.

What I Did

Your own contributions, in simple words.

Designed the Architecture

Services own all logic. Controllers and Livewire stay thin. Blade only shows data.

Built the Order Flow

Pending, processing, shipped and completed, with emails at each step, stock locking and PDF invoices.

Built the Payment Layer

One interface for every gateway, a payment row per attempt, and verified Stripe webhooks.

Built the RAG Pipeline

Product embeddings, vector search, safe prompts, data masking, caching and rate limits.

Central Caching

Public pages are cached, and the cache clears itself when the data behind it changes.

One Design System

Shared UI parts for drawers, menus, modals and tables. One change updates both the shop and the admin panel.

Staff Tools

Reports, dashboard, staff pay tracking, offers, banners, FAQs and live notifications.

Tests and Static Checks

Over 360 Pest tests, Larastan for types and Pint for code style.

Tech Stack

What each tool does here.

Laravel 13 and PHP 8.4

The core framework. Enums, typed code and service classes.

Livewire 4

Interactive pages like cart, checkout and admin tables without writing a separate JavaScript app.

Flux UI 2

Ready UI components (modals, menus, inputs) wrapped in our own shared components.

Tailwind CSS 4

Styling with theme tokens, so brand colors and dark mode change in one place.

Alpine.js

Small client side behaviour like drawers and image zoom.

MySQL

Main database with indexes and foreign keys. Money is stored as whole numbers.

Pest, Larastan, Pint

Tests, type checking and code style.

Integrations and How

Outside services and packages, and how they connect.

Stripe

Called with Laravel's HTTP client, no SDK. Webhooks are checked with an HMAC signature before an order is marked paid.

Gemini AI

Used for embeddings and chat through the HTTP client. The provider is swappable in config.

Fortify

Login, registration, password reset and email verification, with rate limits.

Socialite

Google and Facebook login.

Spatie Permission

Roles and permissions, backed by a PHP enum of every permission.

Spatie Media Library

Product, category, banner and avatar images, with resized versions where needed.

mPDF

Generates the order invoices as PDF.

Mail

Order emails sent after the response, or through the queue when it is turned on.

Quality and Safety

Answers for "How did you keep it safe?"

Permission Checks

Every admin route and action checks a permission.

Rate Limits

Login, checkout, payment return and AI chat are limited.

Safe Payments

Signed webhooks and one payment record per attempt for a clear audit trail.

Private Data Stays Private

The AI never sees IDs, emails or phone numbers.

Correct Stock

Database locks stop two orders from buying the last item.

How It Scales

Answers for "Can it handle growth?"

Caching

Public pages come from cache. Switch the cache to Redis with one setting.

Queues When Needed

Emails can move to a queue worker without code changes.

Efficient Queries

Eager loading, counts in SQL and paginated lists avoid slow pages.

Easy to Extend

New product types, payment gateways and admin areas follow the same clear pattern.
